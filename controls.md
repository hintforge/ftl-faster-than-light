# FTL: Faster Than Light -- Controls

**status:** research-integrated
**last_reconciled:** 2026-06-02

Platform: PC / Steam (mouse + keyboard). FTL is **active-pausable real-time** -- pause freely with Space to issue orders, then unpause to execute.

## Core controls

### Pause / time control
- **Space** -- Pause / unpause (active-pausable real-time; the game runs in real time but you can pause indefinitely to give orders). [Confirmed: P1]

### Crew management
- **Left-click crew member** -- select crew
- **Left-click room** -- order selected crew to move there
- **Right-click** -- deselect / cancel pending order
- **Drag** -- move crew between rooms (works while paused)

### Weapon & targeting
- **1–5 number keys** -- power on/off individual weapons (order matches the weapon bar)
- **Left-click weapon in bar** -- arm weapon for targeting
- **Left-click enemy room** -- set weapon target
- **Right-click weapon** -- de-arm weapon

### Navigation
- **Left-click beacon** -- select jump destination (when the FTL drive is charged)

### Ship systems
- **Left-click system room on own ship** -- interact (repair, de-power)
- Door control panel -- toggle doors / vent rooms to space (used to fight fire and boarders)

### Menus
- **Escape** -- pause menu / options

## Sector-type control notes
- **Nebula / Slug sectors** disable Sensors entirely -- you lose enemy-interior and crew vision unless you carry a Slug crew, a Lifeform Scanner, or hacking/bomb vision. Japanese guides advise judging enemy breaches by O2 drop and the breach "boom" / fire-crackle sounds. See `sections/sector_types.md`.
- **The Last Stand:** "Wait" ticks the map forward and starts the next fight with a full FTL charge; the Flagship caps your Sensors at level 2. *(spoiler: late-game.)*
